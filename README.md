# 辅导员线下培训活动系统（开发版）

当前实现活动发布、编辑、取消、报名、管理员确认参加和按活动或人员查询记录。无需签到。记录保存在服务端 SQLite 中，报名使用数据库事务与唯一约束防止超额和重复报名，取消活动保留报名记录。

管理员工作台的“用户名单管理”支持逐条新增、搜索、修改、停用和启用辅导员。停用会撤销其当前会话但保留历史记录；工号保存后不可修改。名单管理目前不支持导入或导出，列表最多显示 1000 条。

活动学时由管理员发布活动时统一填写。报名本身不计入学时；活动开始后，管理员可在名单中确认参加，或审核通过老师为已报名活动提交的培训经历，确认后按活动学时计入年度排名。同一活动不重复计时；活动已确认参加后不能更改开始时间或学时；取消活动后该活动不计入统计。培训经历当前仅支持文字，不支持上传图片或文件，老师只能选择已报名的活动。

旧开发版的签到和未关联活动的培训经历会保留，但不会自动转换为参加确认或计入排名。旧的未关联活动的经历无法审核，请在需要时重新关联活动提交。旧活动的默认学时为 0，应由管理员核对。

## 本地开发

界面使用 `components/school-brand` 统一呈现学校身份，登录页、首页和管理员工作台使用升华广场照片。品牌主色为 `#25489C`；规范来源为 `UI/20130409-UIS final version.pdf` 的色彩系统页。校徽和照片的原文件保留在 `UI`，小程序资源副本位于 `assets/brand`，校徽通过 `aspectFit` 显示以保留原比例。`UI`、`server` 和临时目录已从小程序打包中排除。

需要 Node.js 22.13 或更高版本（需支持 node:sqlite），后端首次运行需要在 server 目录执行 `npm ci` 安装依赖。PowerShell 在项目目录执行：

```powershell
cd server
npm ci
$env:ENABLE_DEV_LOGIN = '1'
$env:DEV_ADMIN_ID = 'admin'
node server.js
```

在微信开发者工具导入项目，开发环境关闭“校验合法域名”，并保持 `utils/store.js` 的地址为 `http://127.0.0.1:3000`。用测试工号 `admin`、任意姓名及学院登录，可在“我的”进入活动管理。其他英文或数字工号为普通测试账号。测试登录可自由冒用任何测试身份，只能在本地隔离环境使用。服务监听 127.0.0.1；开发者工具的网络环境若无法访问本机，需使用可达的内网地址并限定访问范围。正式小程序需要学校的 HTTPS 域名、证书及微信小程序合法请求域名配置；手机上的 127.0.0.1 指手机自身。

数据库默认保存在 `server/training.db`；可用 `DB_PATH` 指定路径。测试数据库与正式数据必须分开，定期备份数据库及 WAL。测试运行：在 server 目录执行 `npm test`。

## 正式使用前必须完成

1. 实现正式身份认证：学校已说明不接统一登录门户，需确定名单核验及防冒用方式。当前 `/api/auth/dev` 在 `NODE_ENV=production` 下关闭；开发模式仍允许不在名单内的工号创建测试用户，且无法防止冒用，不能当作正式登录。正式环境尚不能登录。
2. 按学校服务器环境配置 HTTPS 反向代理、域名、数据保护和备份，修改小程序 API 地址并配置微信合法域名。不要把开发登录开放到公网。
3. 根据学校培训规则明确报名截止、取消报名、参加确认依据、培训凭证、人员变更及审计要求。当前仅支持管理员在活动开始后确认参加。
4. 当前人员和活动列表最多返回 500 条，尚未实现分页、人员导入、消息通知或完整操作审计。参加确认记录操作管理员，但活动修改没有完整审计日志。
5. 在目标服务器、网络、数据库和真实业务数据下做 500 人并发负载测试，记录响应时间、成功率和数据一致性。当前自动化测试仅覆盖 50 个并发报名；本机尝试 500 个同时连接时出现连接被拒绝，尚未达到要求，需要进一步定位并在目标环境压测。SQLite 单机方案也需要结合实际部署、备份和可用性要求评估。

学校统一身份认证资料到位后，需要实现正式认证接口和小程序登录流程，再完成联调；仅替换 API 地址不能使当前测试登录变成正式登录。

## Excel 导出与审批提醒

管理员在年度学时排名页可按所选年份导出 `.xlsx`，在人员参加情况页可导出全部人员汇总与报名明细（不限于页面 500 条上限）。工号保持文本，时间以北京时间显示；取消活动的明细保留，但不计入学时。下载需要管理员登录凭证，通过微信文档预览菜单保存或分享。正式部署还需把接口 HTTPS 域名加入小程序的 downloadFile 合法域名；开发工具中无法打开文档时应在真机验证。

管理员工作台的审核入口显示红色待审批数字，进入工作台时及停留期间每 30 秒更新；审核页默认只显示待审批记录，审核后刷新数量。活动发布已分为独立页面，活动管理页仅展示列表及管理操作。
