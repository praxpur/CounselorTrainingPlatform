# 济南大学辅导员培训活动平台

支持活动发布、报名、开始前取消报名、扫码/定位签到签退、管理员确认参加、培训经历审核、自行培训与私有证明材料、年度学时统计、Excel 导出和站内通知。

学时直接录入，不按分钟换算；报名和签到本身不计学时。同一活动不重复认定。账号使用学校导入名单与初始密码，首次登录必须修改密码，支持多管理员。

## 使用与部署

本地开发和手机真机调试请参阅[本地调试](docs/本地调试.md)。

后端要求 Node.js 22.16.0 或更高版本，在 `server` 目录运行 `npm ci`。正式使用前必须初始化管理员并导入人员名单。

- [账号与名单导入](docs/账号与名单导入.md)
- [报名、取消与参加规则](docs/报名与参加规则.md)
- [学时单位与旧数据处理](docs/学时单位.md)
- [签到与签退](docs/签到与签退.md)
- [自行培训与证明材料](docs/自行培训与证明材料.md)
- [站内通知](docs/站内通知.md)
- [分页与导出资源边界](docs/分页与导出.md)
- [数据统计与排名](docs/数据统计与排名.md)
- [生产部署、在线备份与恢复](docs/部署与运维.md)

正式部署采用单个 Node 进程、SQLite WAL 和 HTTPS 反向代理；数据库、密码名单、私有材料与备份须放在代码目录之外。生产设置 `NODE_ENV=production`。
当前接口地址仍保留本地/局域网调试配置，待真实域名确定后，使用 `scripts/configure-api.js` 显式配置 HTTPS 地址并设置微信合法域名。
