# 数据统计与排名

管理员工作台统一使用“数据统计与排名”入口，原“人员报名情况”和“年度统计与排名”不再分成两个菜单。旧统计页面链接会跳转到统一页对应维度。

- **按活动**：查看各平台活动及自行培训的报名/提交、已认定、待认定、驳回、取消和认定学时。点击活动查看具体参加人员及状态，零报名的平台活动也显示。
- **按辅导员**：查看每位辅导员年度参加情况，点击查看活动明细。没有记录或已停用的辅导员仍保留，避免遗漏历史。
- **按学院**：汇总当前人员名单的学院/部门，显示辅导员人数、有记录人数与参加情况，点击查看本学院明细。
- **年度排行**：按认定学时排名，相同学时并列。搜索或按学院筛选时保留全校年度总榜名次，不重新从第一名排列。

统一选择年度，按当前维度搜索；数据按活动开始日期（自行培训按参加日期）的北京时间自然年归属。学院采用当前人员归属，不推断历史调动时的学院。

平台参加认定要求活动未取消、报名未取消且已确认参加；自行培训须审核通过。取消、驳回、待审核和未认定记录不计学时。报名/提交总记录数分别归入已认定、待认定/审核、驳回、取消，避免计数与学时含义混淆。
平台活动按活动编号分组；自行培训按同名、同主办方、同参加日期合并，包含各提交人的独立审核结果，不凭名称猜测与平台活动合并。

“导出当前统计”包含当前年度与搜索条件下的完整汇总及参加明细，不只导出已加载页。进入某个活动、辅导员或学院后，“导出本组数据”仅导出该组完整数据；取消、驳回记录保留且认定学时为零。
沿用 Excel 10000 行等资源边界，过大时明确提示分批筛选，工号按文本保留。普通辅导员不能读取或导出管理统计。

辅导员“提交自行参加的活动”入口现在位于**活动中心**，活动记录页仍能查看原有自行培训和驳回后重提。
管理员可从**活动管理 → 活动卡片的“签到/签退设置”**直接开放验证；报名人员页原入口保留。个人页“修改密码”在退出登录上方；管理员“操作审计”已移入功能区。
