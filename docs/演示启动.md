# 展示时怎么启动

1. 双击项目根目录的 **demo.cmd**，保留打开的窗口。
2. 微信开发者工具开启“不校验合法域名”，点击“编译”。
3. 管理员工号 **admin**，辅导员工号 **user**，两个账号密码都是 **Demo12345678!**。

账号会自动准备，演示模式不需要首次改密。再次双击仍恢复这两个演示密码，活动与报名数据不会清空。
只需记住“双击启动演示”，账号和密码每次都会在窗口显示；关闭前可按 Ctrl+C。

本入口用于同一台电脑上的微信开发者工具，接口为 `http://127.0.0.1:3001`。
数据和材料仅在被 Git 忽略的 `tmp/presentation-demo` 中，不使用原 `server/training.db`，也不使用环境里配置的正式库。
演示启动会把 `utils/store.js` 的 API 地址切换到本机演示端口；生产部署前仍须按部署说明设置实际 HTTPS 地址。
固定演示密码和免首次改密只由本地演示启动器写入隔离库，正式登录、生产会话验证和学校账号规则不改变。
