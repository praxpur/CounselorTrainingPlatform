# 分页与导出

活动列表、用户名单、人员参加情况及明细、个人培训记录、年度明细、年度排名、统一审核、报名人员和现场签到记录均支持分页。
小程序每次请求 20 条，可继续加载或返回上一页。长内容列表只保留当前几页，页面会显示当前范围，避免连续加载导致页面数据无限增长。
人员搜索和审核状态筛选在服务端执行，包含尚未加载的记录。快速切换筛选时，旧响应不会覆盖新结果；追加失败保留已有记录，重试不会跳过失败页。

## 接口约定

列表请求使用 `limit=20&offset=0`，`limit` 范围 1—100，`offset` 为非负整数（最多 10000000）。响应包括 `rows`、`total`、`hasMore`、`nextOffset`。
年度明细和现场签到记录分别使用 `records` 字段；年度学时汇总始终覆盖全年所有记录，不能按当前已加载页计算。
年度排名由数据库聚合、排序并计算全局排名，翻页不重排名次，同学时并列。

统一审核接口为 `/api/admin/reviews`，可指定 `status=pending`，将平台经历与自行培训合并排序后分页，并返回全局 `pendingCount`。
人员参加情况支持 `q` 搜索，个人记录支持 `filter=all|pending|reviewed|cancelled`。

原有列表不带分页参数时保留数组响应格式，但查询最多允许 2000 行；超过上限明确返回 400，提示改用分页，不静默截断。
所有 JSON 响应还有 1 MiB 大小上限，长文本导致响应过大时返回 413，提示分页或缩小范围。
统一审核新接口默认返回第一页；审计使用自身的稳定 ID 游标，而不是偏移量。
普通业务列表更新后应刷新；持续有人新增、修改记录时，偏移量分页不承诺形成跨请求的冻结快照。

## Excel 资源边界

工作簿在独立 Worker 中生成，主线程不执行 ExcelJS 工作簿构建与压缩。导出前只选取声明的列，避免复制整份报告或未导出的材料元数据。
同一进程同时只有一个导出任务，其他请求收到 429；超限或取消后释放任务槽。

- 每个工作簿所有表合计最多 10000 行数据，不包含表头。
- 选中单元格的估算内容最多 16 MiB，生成文件最多 32 MiB。
- 工作线程 V8 老生代上限 128 MiB，任务超时 30 秒，失败或下载中断会终止线程。
- 任务槽保持至响应完成或连接关闭，防止慢下载累计大量文件缓冲。

人员导出支持 `year`、精确工号 `id` 或搜索 `q`，明细与人员汇总使用相同范围。
管理页可选择导出年份；进入某个人员详情后，可仅导出该人员年度记录。数据过多时按年份、人员分批导出，不会删减实际记录或伪装成功。
排名导出包含完整所选年度，个人导出包含本人完整所选年度，均不按页面当前页截取，仍受总资源上限约束。

材料上传和下载各最多 4 个并发，下载额度保持至传输完成；私有文件每份最多 5 MiB。
SQLite 查询仍是同步读取，使用索引与分页控制返回量，正式环境仍需测试真实数据量、磁盘和网络表现，不能仅凭本地测试承诺生产容量。
