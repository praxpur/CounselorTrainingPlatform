# 学时单位

平台直接填写学时，不按分钟或活动自然时长折算。
发布、修改活动时填写的数值即为审核或确认参加后认定的学时。支持 0—60000、最多两位小数；例如填写 `1.5`，认定、排名、年度汇总和 Excel 中都为 `1.5` 学时。
取消或未认定的活动不计入统计，同一活动不重复计时。月度、年度及排名汇总按两位小数处理，避免浮点尾差。

## 数据与接口调整

接口字段统一使用 `creditHours`、`creditedHours`、`recognizedHours`、`totalHours`；月度数据使用 `hours`。
数据库对应字段为 `credit_hours` 与 `credited_hours`。新库使用 REAL 数值列。

启动时会在一个事务内将旧字段 `credit_minutes`、`credited_minutes` 重命名，**原数值完全保留，不除以 45 或 60，也不按活动时长重算**。例如旧值 `60` 迁移后仍是 `60`。
重复启动不会再次迁移。如果新旧字段同时存在，启动会拒绝处理，要求人工核对，避免猜测采用哪个值。

正式数据迁移前应执行在线安全备份，并让学校核对历史数值是否已符合学时口径。以前确实按分钟填写的记录需要学校逐条认定正确学时，再修正数据；平台不会擅自推断换算规则。
前后端须同步部署；新接口不继续接受容易混淆的 `creditMinutes` 字段。

本次迁移验证使用独立测试数据库，未启动迁移开发库或学校正式库。
